# Acknowledgments

Asteroids is an independent learning project inspired by Atari's original
*Asteroids* arcade game.

The project was initially developed interactively with the Gemini CLI.
[Ebitengine](https://ebitengine.org/) and Go provide the cross-platform game
loop, rendering, input, and audio foundations.

Automated coding tools and assistants are additionally attributable through
the repository's commit history.
